# Розумник на Cloudflare Pages

Ця версія віддає сторінки й навчальні матеріали як статичні файли. Перевірка тестів працює окремо через Pages Function. Під час збірки Python готує навчальні файли; Flask не імпортується і сервер Flask не запускається.

## Публікація

1. Створи проєкт Cloudflare Pages із GitHub-репозиторію `pavlijsvatoslav-cmyk/rozumnyk` після злиття міграційної гілки.
2. Обери гілку, з якої Pages має публікувати сайт.
3. Вкажи кореневу папку репозиторію, команду збірки `pnpm build` і папку результату `dist`.
4. Після першої успішної збірки відкрий видане Pages-посилання й перевір урок та тест.

Cloudflare Pages будує проєкт із Node.js і Python. Код не потребує Google API-ключа, паролів чи інших змінних середовища.

Статичні файли на безкоштовному плані мають безкоштовні необмежені запити. Функція перевірки тесту рахується в денну квоту Workers Free — до 100 000 запитів на день. [Умови Pages Functions](https://developers.cloudflare.com/pages/functions/pricing/).

## Локальний запуск

```text
pnpm install
pnpm dev
```

`pnpm dev` спершу готує навчальні матеріали, потім запускає локальний режим Pages разом із перевіркою тестів на `http://127.0.0.1:8788`.

Прогрес зберігається тільки у браузері цього пристрою. Ця версія не створює профілі учнів, не збирає електронні адреси й не синхронізує особисті нотатки.
