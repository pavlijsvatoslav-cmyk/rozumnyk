# Розумник — дизайн-система

Версія **1.0** · Інтерфейс навчального сайту · Код стилів: `static/design-system.css`

## Візуальна мова

Основа — редакційний навчальний досвід: тепле світле тло, темний текст, насичений лаймовий акцент і великі заголовки. Головна знайомить із платформою через масштабну типографіку й абстрактний геометричний 3D-об’єкт; класи розкладені в горизонтальну шкалу. Плавне прокручування на Lenis доповнює природну навігацію браузера, але не перехоплює її; уроки лишаються читабельними й доступними.

## Токени

### Типографіка

Основний шрифт: `Inter`, системний запасний ряд — `Segoe UI`, `Arial`, sans-serif. Текст уроків: 13–16 px із міжряддям `1.6`; малі підписи не опускати нижче 11 px; заголовки масштабуються від 28 px, головний заголовок — через `clamp()`.

### Відступи, радіуси, глибина

| Сімейство | Значення |
|---|---|
| Відступи `--space-1…10` | 4, 8, 12, 16, 20, 24, 32, 40 px |
| `--radius-control` / `--radius-card` / `--radius-panel` | 10 / 17 / 22 px |
| `--radius-pill` | 999 px |
| `--elevation-1…3` | Контрол, картка, картка при наведенні; кожен має контактну тінь і м’яку тінь від падіння |
| `--depth-card` / `--depth-control` | 8 / 4 px |
| `--motion-fast` / `--motion-standard` / `--motion-slow` | 160 / 260 / 600 ms |

Сітка: основна ширина до 1130 px; контрольні точки — 800 px для планшетної сітки та 540 px для одноколонкового мобільного компонування. Іконки — прості емодзі та геометричні знаки, без змішування контурного й фотореалістичного стилів.

## Компоненти

| Компонент | Варіанти та стани | Правила використання й доступності |
|---|---|---|
| Навігація | Верхня панель, перемикач класу, активне посилання | Видиме активне посилання; короткі підписи; фокус клавіатури має бути помітним. |
| Кнопка `.button` | Основна, наведена, натиснута | Основна дія одна на секцію; видимий текст дієслово + результат; не використовувати лише колір для стану. |
| Картка | Предмет, інструмент, професія, прогрес | Вся клікабельна картка має бути посиланням лише коли веде до одного призначення; не вкладати кнопки в таке посилання. 3D-нахил обмежений кількома градусами. |
| Поле пошуку `.topic-search` | Порожнє, введений запит, фокус | Завжди має `label` або `aria-label`; пошук не потребує додаткової кнопки. |
| Select / фільтр | Усі, пройдені, не пройдені | Підписуємо для читачів екрана; не покладаємося на placeholder як на єдину назву. |
| Радіокнопка / варіант відповіді | Не вибрано, вибрано, перевірено | Групуємо одним запитанням; кожен варіант має текстову назву й доступну область натискання. |
| Панель уроку | Пояснення, приклад, правило, завдання, попередження | Заголовок пояснює призначення; порядок відповідає навчанню: ідея → приклад → практика. |
| Контрольна `.quiz` | Звичайна, НМТ, успішно, потрібно повторити | Показує кількість запитань, результат і поріг; повідомлення не передається лише кольором. |
| Значок / статус | Тема завершена, НМТ, успіх, помилка | Короткий текст або символ із доступною назвою; значок не повинен заміняти інформацію. |
| Порожній стан `.empty` | Немає тем або результатів | Пояснює, чому порожньо, і дає наступну корисну дію. |
| Прогрес | Смуга й текстова кількість тем | Показує числа як текст; смуга лише доповнює, не замінює числовий результат. |
| Поле нотатки | Порожнє, введений текст, збережене | Зрозумілий підпис, видимий статус автозбереження та можливість редагувати звичайною клавіатурою. |

Модальні вікна, вкладки, таблиці, тости, аватари й підказки зараз не є частиною основного сайту. Якщо вони з’являться, спершу додай конкретний сценарій використання та клавіатурну й екранно-читачну поведінку; не вводь компоненти «про запас».

## Патерни

- **Пошук і фільтр:** пошук за назвою + явний фільтр статусу; збережи поточну кількість знайдених елементів, якщо список стане довгим.
- **Форма контрольної:** одне запитання — одна група відповідей; потрібен вибір до відправлення; після відповіді покажи бал, поріг і дію для повторення.
- **Порожній результат:** поясни, що саме не знайдено, і як очистити пошук або повернутися до всіх тем.
- **Особисті інструменти:** явно повідомляй, що дані зберігаються в локальному браузері й не синхронізуються між пристроями.

## Доступність і рух

- Контраст звичайного тексту прагне до WCAG AA (4.5:1); перевіряй нові пари кольорів окремо.
- Забезпечуй видимий `:focus-visible`, семантичні кнопки й посилання, підписані поля та мінімальну область натискання близько 44×44 px на мобільному.
- Усі об’ємні й плаваючі рухи мають поважати `prefers-reduced-motion: reduce`; декоративні елементи мають `aria-hidden="true"`.
- Не передавай «правильно/неправильно», активність або тип контролу лише відтінком; додавай текст, форму чи піктограму.
- Уникати надмірного паралаксу, довгих обертань біля тексту та глибоких нахилів інтерактивних цілей.

## Зміни системи

1. Спершу перевір, чи потрібна зміна повторюваному компоненту, а не лише одній сторінці.
2. Нові кольори називай за роллю (`--color-state-warning`), а не за відтінком.
3. Зміни токени й компонентні правила в `static/design-system.css`; оновлюй цю таблицю в тому самому запиті.
4. Не змінюй структуру сторінки чи навчальний текст як побічний ефект стилізації.
5. Версія `1.x` сумісна з наявними класами; перейменування класів або зміна семантики токенів потребує нової мажорної версії й міграційної нотатки.

## Головна та навігація класів

Головна використовує масштабний заголовок, геометричну 3D-композицію та горизонтальну шкалу класів 5–11. Кожен номер лишається звичайним посиланням на відповідний клас; кількість предметів і тем формується з `curriculum.py`. Плавне прокручування підключається через офіційну бібліотеку Lenis і поважає `prefers-reduced-motion`; за недоступності CDN лишається звичайне прокручування браузера. Предмети, уроки, контрольні, інструменти й прогрес працюють через наявні маршрути Flask.
