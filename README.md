# Розумник — навчальний сайт для 5–11 класів

Локальний сайт на Flask українською мовою. Має перемикач класів, предметні картки, CSS 3D-анімації, тематичні уроки, приклади, вправи, контрольні роботи, пошук і фільтри тем, профорієнтацію та інструменти для планування й повторення. У 5–7 класах контрольна має 5 запитань, у 8–11 — 12; для зарахування потрібно щонайменше 4 або 9 правильних відповідей відповідно. Навчальний прогрес та особисті налаштування зберігаються в локальному сховищі браузера на цьому пристрої.

## Запуск у Windows

1. Установи Python 3.10 або новіший з [python.org](https://www.python.org/downloads/).
2. Поклади `app.py` і `curriculum.py` в одну папку.
3. Відкрий PowerShell у цій папці та виконай:

   ```powershell
   py -m pip install Flask
   py app.py
   ```

4. Відкрий `http://127.0.0.1:5000` у браузері. Зупинити сайт можна клавішами `Ctrl+C` у вікні PowerShell.

HTML сторінок зібраний у `app.py`, а спільні 3D-токени й стилі компонентів — у `static/design-system.css`. На головній для 3D-сцени учня підключається Three.js через CDN; без WebGL або доступу до CDN показується резервний варіант. Для локального запуску потрібні `app.py`, `curriculum.py` та вся папка `static` (включно з `favicon.svg`). Папка `templates` для поточної версії не потрібна.

## Як відкрити сайт для всіх в інтернеті

1. Створи репозиторій на GitHub і додай у нього `app.py`, `curriculum.py`, `requirements.txt`, `DESIGN_SYSTEM.md` і всю папку `static` (`favicon.svg` та `design-system.css`). Якщо не хочеш показувати код, зроби репозиторій приватним.
2. Створи обліковий запис на Render і вибери **New → Web Service**. Під’єднай GitHub та обери репозиторій із сайтом.
3. У налаштуваннях сервісу вкажи:
   - **Language:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app`
4. Натисни **Create Web Service**. Після розгортання Render покаже адресу на кшталт `rozumnyk.onrender.com`; надішли її друзям, учителю чи в шкільний чат.

Безкоштовний план підходить для пробного розгортання: після 15 хвилин без запитів сервіс може заснути, тому перше відкриття буде повільнішим. Render не рекомендує безкоштовні вебсервіси для виробничого використання. Перед публічним запуском для багатьох людей перевір актуальні обмеження й витрати та обери план із потрібною надійністю. Власну коротку адресу, наприклад `rozumnyk.com`, можна окремо придбати й під’єднати в налаштуваннях Render.

Щоб сайт легше знаходили: поширюй посилання в навчальних спільнотах, додай QR-код на плакат або презентацію, а після публікації додай сайт у Google Search Console і надішли карту сайту `https://твій-домен/sitemap.xml`. Файли `/robots.txt` і `/sitemap.xml` створюються застосунком автоматично. Карта містить сторінки класів і предметів; теми доступні через посилання на сторінках предметів. Надсилання карти — лише підказка пошуковику й не гарантує індексації або місця в результатах. Для Render використовується автоматична адреса сервісу; коли під’єднаєш власний домен, задай у Render Environment змінну `PUBLIC_BASE_URL` зі значенням `https://твій-домен`, щоб канонічні посилання та карта вказували на нього.

Для поширення сайт автоматично додає картинку-прев’ю у форматі PNG розміром 1200 × 630. Коли надсилаєш посилання, вигляд картки залежить від того, чи оновив сервіс попереднє прев’ю; після нової публікації деякі соцмережі можуть зберігати стару картинку певний час.

Початкову картинку можна перебудувати на Windows командою `powershell -ExecutionPolicy Bypass -File .\work\build_social_card.ps1`; вона збереже результат у `static\social-card.png`.

План першого публічного запуску, пілоту з учителями, залучення аудиторії й перевірки моделей доходу дивись у [LAUNCH_AND_REVENUE_PLAN.md](LAUNCH_AND_REVENUE_PLAN.md). Це робочий план із гіпотезами, а не прогноз відвідуваності чи заробітку.

## Навчальний вміст

- 5 клас — базова програма сайту.
- 6 клас — продовження тем 5–6 циклу; математику зручно розділено на блоки алгебри й геометрії, а фізика та хімія подані як додаткові вступні блоки інтегрованого природничого курсу.
- 7 клас — алгебра, геометрія, біологія, географія, фізика й хімія подані окремо.
- У 5–7 класах додано 2 004 нові мікротеми (усього 2 338 тем): кожну вихідну тему розгорнуто в шість занять про ключове поняття, приклад, послідовність дій, типову помилку, застосування та самостійну практику.
- Для 6 класу на сторінках предметів показано підручники-орієнтири: математика — Олександр Істер (2023); зарубіжна література — Ольга Ніколенко, Наталія Рудніцька та інші автори (2023); інформатика — Ольга Коршунова й Ігор Завадський (2023); українська мова — Олександр і Віктор Заболотні (2023).
- 8–9 класи — 1 080 навчальних тем: 20 напрямів по 27 уроків у кожному класі. Кожну широку тему розбито на опрацювання понять і покрокову практику; кожен курс завершується міжтематичним практикумом, практичним застосуванням і проєктом. Є мовно-літературні предмети, алгебра й геометрія, природничі науки, історія, інформатика, технології, мистецтво, здоров’я та фізична культура. Громадянська освіта, фінансова грамотність та етика позначені як додаткові курси, які школа може інтегрувати або не обирати.
- 10–11 класи — 4 032 додаткові заняття: по 2 016 на клас у 21 навчальному напрямі. Кожна з 24 опорних тем розглядається через поняття, покроковий розбір, практику та аналіз типових помилок.
- Показані числа — кількість навчальних занять у бібліотеці, а не кількість незалежно перевірених унікальних питань або повна копія навчальних програм і підручників. Частина широких тем подана кількома заняттями; зміст потрібно звіряти з учителем і першоджерелами.
- 11 клас має окремий НМТ-фокус: українська мова, алгебра й геометрія (математика), історія України, а також напрями на вибір — англійська, українська література, біологія, географія, фізика й хімія. Уроки містять підказки з розв’язування тестових завдань і контрольні з 12 питань. Це тематичний тренажер, а не повний демоваріант НМТ.
- Українська та англійська мови мають розширені тематичні добірки.
- Для ключових тем є правила, кроки розв’язання, типові помилки й додаткові завдання; найбільше розширено алгебру та геометрію 7 класу, українську й англійську мови, хімію та українську літературу.
- Етика й добросусідство — вибірковий курс.

## Профорієнтація

На сторінці **«Професії»** можна порівняти освітні можливості після 9-го класу та після 12-го класу й пройти тест із 12 запитань. Результат показує один або два напрями інтересів із прикладами професій і можливим наступним освітнім кроком. Це орієнтир для роздумів, а не психологічний тест і не гарантія професійного успіху.

Після 9-го класу серед можливих варіантів є продовження навчання в академічному ліцеї, професійна освіта та вступ до коледжу за правилами конкретного закладу. Профільна старша школа в Україні впроваджується поетапно, тому доступність ліцеїв і профілів залежить від громади та року. Після 12-го класу можна розглядати вступ до закладу вищої чи фахової передвищої освіти, професійне навчання або роботу; вимоги та вступні випробування потрібно перевіряти для року вступу.

Для загального ознайомлення дивись [пояснення МОН про академічні ліцеї](https://mon.gov.ua/news/de-navchatymutsia-starshoklasnyky-znaidit-svii-akademichnyi-litsei-u-hromadi), [портал професійної освіти](https://proftech.mon.gov.ua/) і [правила вступу до закладів вищої освіти](https://mon.gov.ua/osvita-2/vishcha-osvita-ta-osvita-doroslikh/vstupna-kampaniia-do-zvo/vstupna-kampaniia-do-zakladiv-vyshchoi-osvity-2026-roku/poriadok-pryiomu-dlia-zdobuttia-vyshchoi-osvity-v-2026-rotsi). Щороку звіряй вимоги з офіційною інформацією МОН та обраного закладу.

## Навчальні інструменти

- Пошук на головній сторінці знаходить предмети; на сторінці предмета можна шукати урок за назвою та відфільтрувати завершені або ще не пройдені теми.
- Блок на головній запам’ятовує останній відкритий урок і пропонує продовжити його, навіть після перемикання класу.
- Урок можна надіслати через системне меню поширення або скопіювати посилання; у посилання не потрапляють оцінки чи особисті нотатки.
- На сторінці **«Мої інструменти»** можна скласти план на тиждень, вибравши предмети, кількість днів і тривалість занять.
- У кожному уроці є закладка й особиста нотатка. Після контрольної сайт додає неправильні відповіді до черги повторення; їх можна спробувати ще раз і перейти до інших тем цього предмета.
- Відзнаки залежать від кількості зарахованих тем; серія занять рахується за календарними днями, коли учень працював із контрольними.
- Налаштування доступності: збільшення шрифту, контрастний режим і озвучення сторінки за допомогою браузера. Перемикач UA/EN перекладає частину пунктів меню; навчальний зміст лишається українським.
- Закладки, нотатки, план, помилки, досягнення, останній відкритий урок і параметри доступності зберігаються локально в браузері. На іншому пристрої вони автоматично не з’являться.
- Сторінка **«Приватність і дані»** пояснює, що саме зберігається локально, як контрольні надсилають відповіді для підрахунку та як видалити навчальні дані «Розумника» з цього браузера.

## Дизайн-система

Повторювані кольори, відступи, заокруглення, тіні, motion-тривалості й стилі 3D-компонентів зібрані у `static/design-system.css`. Токени мають семантичні імена, наприклад `--color-bg-surface` і `--color-state-success`. Документ [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md) описує їх застосування, компоненти, стани, доступність і правила змін. Темні значення кольорів задокументовані для майбутнього режиму; перемикача теми сайт поки не має.

МОН затвердило програму старшої школи для 10–12 класів академічного спрямування, а реформа профільної школи впроваджується поетапно. Тому 10–11 класи на сайті — широкий тематичний огляд, а не розклад конкретного ліцею чи копія підручника. Профіль, порядок тем і актуальний формат НМТ звіряй із закладом освіти та офіційними матеріалами УЦОЯО.
