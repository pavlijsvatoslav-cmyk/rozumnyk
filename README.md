# Розумник — навчальний сайт для 5–9 класів

Локальний сайт на Flask українською мовою. Має перемикач класів, картки предметів, анімовані сторінки уроків, пояснення, приклади, вправи, контрольні роботи й сторінку прогресу. У 5–7 класах контрольна має 5 запитань і для зарахування потрібно 4 правильні відповіді. У 8–9 класах контрольна має 12 запитань і для зарахування потрібно 9 правильних відповідей. Прогрес зберігається в локальному сховищі браузера на цьому пристрої.

## Запуск у Windows

1. Установи Python 3.10 або новіший з [python.org](https://www.python.org/downloads/).
2. Поклади `app.py` і `curriculum.py` в одну папку.
3. Відкрий PowerShell у цій папці та виконай:

   ```powershell
   py -m pip install Flask
   py app.py
   ```

4. Відкрий `http://127.0.0.1:5000` у браузері. Зупинити сайт можна клавішами `Ctrl+C` у вікні PowerShell.

HTML і стилі вбудовані в `app.py`, тому папки `templates` і `static` не потрібні.

## Як відкрити сайт для всіх в інтернеті

1. Створи репозиторій на GitHub і додай у нього `app.py`, `curriculum.py` та `requirements.txt`. Якщо не хочеш показувати код, зроби репозиторій приватним.
2. Створи обліковий запис на Render і вибери **New → Web Service**. Під’єднай GitHub та обери репозиторій із сайтом.
3. У налаштуваннях сервісу вкажи:
   - **Language:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app`
4. Натисни **Create Web Service**. Після розгортання Render покаже адресу на кшталт `rozumnyk.onrender.com`; надішли її друзям, учителю чи в шкільний чат.

Безкоштовного плану вистачить для першого запуску, але після 15 хвилин без відвідувачів сайт засинає, тому перше відкриття може бути повільним. Якщо потрібен постійно швидкий доступ для багатьох людей, обери платний сервер. Власну коротку адресу, наприклад `rozumnyk.com`, можна окремо придбати й під’єднати в налаштуваннях Render.

Щоб сайт легше знаходили: поширюй посилання в навчальних спільнотах, додай QR-код на плакат або презентацію, а після публікації зареєструй сайт у Google Search Console та попроси Google просканувати його. Поява в пошуку займає час і не гарантує певної кількості відвідувачів.

## Навчальний вміст

- 5 клас — базова програма сайту.
- 6 клас — продовження тем 5–6 циклу; математику зручно розділено на блоки алгебри й геометрії, а фізика та хімія подані як додаткові вступні блоки інтегрованого природничого курсу.
- 7 клас — алгебра, геометрія, біологія, географія, фізика й хімія подані окремо.
- У 5–7 класах додано 2 004 нові мікротеми (усього 2 338 тем): кожну вихідну тему розгорнуто в шість занять про ключове поняття, приклад, послідовність дій, типову помилку, застосування та самостійну практику.
- Для 6 класу на сторінках предметів показано підручники-орієнтири: математика — Олександр Істер (2023); зарубіжна література — Ольга Ніколенко, Наталія Рудніцька та інші автори (2023); інформатика — Ольга Коршунова й Ігор Завадський (2023); українська мова — Олександр і Віктор Заболотні (2023).
- 8–9 класи — 1 080 навчальних тем: 20 напрямів по 27 уроків у кожному класі. Кожну широку тему розбито на опрацювання понять і покрокову практику; кожен курс завершується міжтематичним практикумом, практичним застосуванням і проєктом. Є мовно-літературні предмети, алгебра й геометрія, природничі науки, історія, інформатика, технології, мистецтво, здоров’я та фізична культура. Громадянська освіта, фінансова грамотність та етика позначені як додаткові курси, які школа може інтегрувати або не обирати.
- Українська та англійська мови мають розширені тематичні добірки.
- Для ключових тем є правила, кроки розв’язання, типові помилки й додаткові завдання; найбільше розширено алгебру та геометрію 7 класу, українську й англійську мови, хімію та українську літературу.
- Етика й добросусідство — вибірковий курс.

МОН публікує модельні програми 7–9 класів для окремих предметів та інтегрованих курсів; школа обирає варіант, тому порядок і назви тем можуть різнитися. Наповнення 8–9 класів на сайті — тематичний навчальний огляд із поясненнями й прикладами, а не дослівний зміст одного конкретного підручника. Узгоджуй порядок тем із учителем і підручником свого класу.
