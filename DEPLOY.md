# Розгортання «Розумника» через GitHub + Render

## 1. Покладіть файли в репозиторій
У корені репозиторію `rozumnyk` мають бути (поруч з `app.py` і `curriculum.py`):
`main.py`, `teacher_platform.py`, `seed_demo.py`, `grade9_books.py`, `grade9_more.py`, `requirements.txt`, `render.yaml`, `.gitignore`.
`main.py` підключає додаткові теми й кабінет учителя.

Якщо `requirements.txt` у вас уже був — залиште в ньому ваші рядки й переконайтеся, що є `Flask` та `gunicorn`.

Через термінал:
```
git add .
git commit -m "Теми 9 класу та кабінет вчителя"
git push
```
Або через сайт GitHub: Add file → Upload files → перетягніть файли → Commit changes.

## 2. Render
1. render.com → New → **Blueprint** → виберіть репозиторій (Render прочитає `render.yaml`).
2. Заповніть змінні:
   - `TEACHER_INVITE_CODE` — код, який даватимете вчителям для реєстрації;
   - `DEMO_PASSWORD` — пароль демо-вчителя для презентації (демо-клас створиться сам; пошта `demo@rozumnyk.example`);
   - `PUBLIC_BASE_URL` — адреса сайту після першого розгортання (`https://….onrender.com`), потім збережіть і перезапустіть.
   - `SECRET_KEY` у Render створюється через `generateValue: true` у `render.yaml`; залиште це значення незмінним між розгортаннями.
3. Після кожного `git push` Render оновлює сайт сам.

## Локальний ключ сесій
Для запуску на комп’ютері ключ зберігається у файлі `.env` у корені проєкту. `main.py` читає його до налаштування сесій, якщо змінна `SECRET_KEY` ще не задана в середовищі. Файл `.env` уже виключений у `.gitignore` — не додавайте його до GitHub і не надсилайте іншим. У Render використовується окремий секрет із налаштувань сервісу. Заміна ключа завершує активні входи, але не змінює паролі.

Команда запуску: `gunicorn main:app --workers 1 --threads 4 --timeout 60`.

Перемикач `EN` використовує вбудований словник у браузері й не потребує API-ключа, білінгу чи мережевого запиту до перекладача. Основний інтерфейс і типові підказки доступні англійською; переклад пояснень уроків додається поступово. Текст, введений користувачем, не перекладається.

## 3. Безкоштовний план і дані
На безкоштовному плані сайт «засинає» після періоду без запитів (перший запит після сну довгий — відкрийте сайт за кілька хвилин до показу), а база класів і завантажені файли **не зберігаються** між перезапусками й розгортаннями. Тому безкоштовний план годиться для показу: демо-клас створюється заново з `DEMO_PASSWORD`. Для реальних класів потрібен платний план із диском: у `render.yaml` змініть `plan: free` на платний, розкоментуйте блок `disk` і додайте змінну `DATA_DIR=/var/data`. Актуальні ціни дивіться на render.com/pricing. Резервні копії `DATA_DIR` робіть окремо.

## 4. Перевірка
Відкрийте `/teacher`, увійдіть демо-вчителем, відкрийте клас «9-А (демо)». Сторінка `/join` — вхід учнів за кодом.

## 5. Космічна тема
Тема (чорний фон із зірками, темні картки, без 3D-учня) підключається в `main.py` модулем `cosmic_theme.py`; `app.py` і `static/design-system.css` не змінюються. Щоб повернути світлий вигляд, закоментуйте в `main.py` два рядки з `cosmic_theme`.
